# C3++ Bootstrapping Compiler

A C3++ to C transpiler written in C3++ itself. **C3++ has no preprocessor.**

## What is C3++?

C3++ is an object-oriented extension of C3, a systems programming language that:
- **Has no preprocessor** — no `#include`, `#define`, `#ifdef`, `#pragma`
- Uses `module name;` to declare modules
- Uses `import name;` to import standard library modules
- Uses `const NAME = value;` for compile-time constants (ALL_CAPS convention)
- Uses `fn TYPE name(params) { ... }` for function declarations
- Has a rich type system: `string`, `bool`, `ichar`, `ushrt`, `uint`, `ulong`, `iptr`, `uptr`, `sz`, `usz`, etc.

## Bootstrapping Chain

```
Phase 1:  Python c3ppc  ──compiles──>  C code  ──GCC──>  c3ppc-bootstrap
Phase 2:  c3ppc-bootstrap ──compiles──>  C code  ──GCC──>  c3ppc-self
Phase 3:  c3ppc-self ──compiles──>  any C3++ program
```

The bootstrap compiler (`c3ppc-bootstrap`) is compiled by the Python `c3ppc` compiler.
Then it compiles itself (self-compilation) to produce `c3ppc-self`.
Both compilers produce identical output.

## Quick Start

```bash
# Build everything
make all

# Run full bootstrapping chain
make chain

# Or step by step:
make                 # Build c3ppc-bootstrap
make self-test       # Self-compilation test
make test            # Compile hello.c3pp
```

## Usage

```bash
./c3ppc-bootstrap <input.c3pp> [-o output.c]
./c3ppc-bootstrap --help
./c3ppc-bootstrap --version
```

## Example: Hello World (no preprocessor!)

```c3pp
// hello.c3pp — pure C3++, no #include, no #define
module hello;

import stdio;

fn int main() {
    printf("Hello, World!\n");
    return 0;
}
```

Generated C:
```c
/* Generated by c3ppc bootstrap compiler */
/* C3++ has no preprocessor -- includes from import */

#include <stdio.h>

/* Module: hello */

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## How the Transpiler Works

1. **Module/Import**: `import stdio;` → `#include <stdio.h>`
2. **Constants**: `const MAX = 100;` → `#define MAX 100`
3. **Functions**: `fn int main()` → `int main()`
4. **Types**: `string` → `char*`, `bool` → `int`, `ichar` → `signed char`, etc.
5. **Control flow**: `if`, `for`, `while`, `switch` pass through unchanged
