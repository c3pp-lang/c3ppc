# c3ppc - C3++ to C Compiler

A compiler for **C3++**, an object-oriented extension of the C3 programming language, built using [PyLGEN](https://github.com/YonyUk/pylgen).

## Overview

C3++ extends the C3 systems programming language with object-oriented features while maintaining C3's focus on performance, safety, and familiarity with C syntax.

### C3++ Features

- **Classes** with single inheritance
- **Virtual methods** and method overriding
- **Abstract classes** and interfaces
- **Constructors** and destructors
- **Access modifiers** (public, private, protected)
- **Structs** (value types)
- **Enums** with associated values
- **Functions** with type inference
- **Defer** statements for cleanup
- **Foreach** loops
- **Pattern matching** in switch statements

### C3 Base Features

- C-compatible syntax
- Modules and imports
- Functions with named parameters
- Built-in optional types
- Slices and arrays
- Generic types
- Compile-time evaluation
- Error handling with optionals

## Usage

### Command Line

```bash
# Compile a C3++ file
c3ppc input.c3pp -o output.c

# Check for errors only
c3ppc --check-only input.c3pp

# Verbose mode
c3ppc -v input.c3pp -o output.c

# Print AST
c3ppc --emit-ast input.c3pp
```

### Python API

```python
from c3ppc.compiler import C3ppCompiler, CompilerOptions

# Create compiler with options
options = CompilerOptions(
    verbose=True,
    emit_ast=False
)
compiler = C3ppCompiler(options)

# Compile source code
source_code = """
module example;

fn int add(int a, int b) {
    return a + b;
}

fn int main() {
    int result = add(10, 20);
    printf("Result: %d\\n", result);
    return 0;
}
"""

c_code = compiler.compile(source_code)
print(c_code)
```

## Example

### Input (C3++)

```c3pp
module animal;

class Animal {
    string name;
    int age;
    
    Animal(string name, int age) {
        this.name = name;
        this.age = age;
    }
    
    virtual string speak() {
        return "...";
    }
}

class Dog extends Animal {
    string breed;
    
    Dog(string name, int age, string breed) {
        super(name, age);
        this.breed = breed;
    }
    
    override string speak() {
        return "Woof!";
    }
}

fn int main() {
    Dog dog = new Dog("Buddy", 5, "Golden Retriever");
    printf("%s\\n", dog.speak());
    return 0;
}
```

### Output (C)

```c
/* Generated by c3ppc - C3++ to C compiler */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Animal {
    char* name;
    int age;
};

void Animal_constructor(struct Animal* self, char* name, int age) {
    self->name = name;
    self->age = age;
}

char* Animal_speak(struct Animal* self) {
    return "...";
}

struct Dog {
    char* name;
    int age;
    char* breed;
};

void Dog_constructor(struct Dog* self, char* name, int age, char* breed) {
    Animal_constructor((struct Animal*)self, name, age);
    self->breed = breed;
}

char* Dog_speak(struct Dog* self) {
    return "Woof!";
}

int main() {
    struct Dog* dog = (struct Dog*)malloc(sizeof(struct Dog));
    Dog_constructor(dog, "Buddy", 5, "Golden Retriever");
    printf("%s\n", Dog_speak(dog));
    return 0;
}
```

## Architecture

```
c3ppc/
├── lexer/           # Lexical analysis
│   ├── tokens.py    # Token type definitions
│   └── lexer.py     # Lexer implementation
├── parser/          # Syntax analysis
│   ├── grammar_symbols.py  # Grammar symbols
│   ├── grammar.py   # Grammar rules
│   └── reductors.py # AST builders
├── ast/             # Abstract Syntax Tree
│   └── nodes.py     # AST node definitions
├── semantic/        # Semantic analysis
│   └── analyzer.py  # Type checker and scope resolver
├── codegen/         # Code generation
│   └── generator.py # C code generator
├── compiler.py      # Main compiler entry point
└── examples/        # Example C3++ programs
```

## Pipeline

1. **Lexical Analysis**: Tokenize source code using PyLGEN's lexer
2. **Syntax Analysis**: Parse tokens into AST using LALR(1) parser
3. **Semantic Analysis**: Type checking, scope resolution, access control
4. **Code Generation**: Generate equivalent C code
